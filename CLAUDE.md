# Strandsmart Revamp Project
## Architecture
- Root: Contains project configuration.
- /src: Main source code.
- /components: UI elements to be refactored.

## Style Guide
- Primary Color Palette: **Custom Greens** (Avoid the default template greens; aim for a unique, modern green brand identity).
- Task: Deep UI revamp to remove all Creative Tim branding, boilerplate "garbage," and legacy demo code.
- Goal: Fully original-feeling UI so the code can be claimed as 100% Strandsmart.

## Working Rules
- **DO NOT use the Agent tool.** It causes parameter errors with the current proxy.
- Perform all refactoring tasks in the main chat using `read_file`, `write_to_file`, and `edit_file`.
- Work section-by-section (e.g., Global styles first, then Layout, then individual Components).
- Always check for "Creative Tim" strings or logos before finishing a component revamp.
